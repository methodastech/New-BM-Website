ESKAYVIE MINDTROPIC — WEBSITE (clean build, 2026-07-08)
=======================================================

This folder is the COMPLETE, self-contained website. Nothing else is needed.

  index.html   → the whole site (one file)
  assets/      → the 73 images, videos, audio and label files it uses

There are NO old versions, backups or unused mascot files in here — only what
the site actually loads.

TO VIEW IT
  Open index.html in a browser, or serve the folder, e.g.:
    python3 -m http.server 8000
  then visit http://localhost:8000

NOTES
  • Three.js (for the 3D bottle) and Google Fonts load from the internet (CDN),
    so an internet connection is needed the first time.
  • Best viewed on a phone and on desktop — both layouts are built in.
