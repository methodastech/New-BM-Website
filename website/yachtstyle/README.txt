Yacht Style Arabia, Prototype Web 1 (2026-10-28)

Open it with a local web server (the films, the CMS and the Proposal tab need one):

  1. Unzip, then open a terminal in this folder.
  2. Run:  python3 -m http.server 8863
  3. Open: http://localhost:8863

Pages
  index.html              the prototype home page
  portal.html             the CMS sample (passcode yachtstyle321, or Emergency access)
  proto/reviews.html      section template
  proto/article.html      article template
  prototype-single.html   the home page as one file (opens without a server)
  pack.html, audits.html, client.html, web.html   the four tabs of the bar: Proposal, Brand Audit, Brand Documents, Web Prototype 1
  pack/                   the Proposal tab's documents

The films stream from Yacht Style's YouTube channel, so they need an internet connection.
